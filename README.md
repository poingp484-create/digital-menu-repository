# digital-menu-repository

## Adapt your teaching to the age group

`index.html` is a single-page, printable teacher reference for faith formation
lessons, organised by age group:

| Classes | Focus | Approach |
| --- | --- | --- |
| 1–2 | Discover Jesus | Short activities, concrete objects, movement and repetition |
| 3–5 | Explore and participate | Stories, puzzles, teamwork and practical applications |
| 6–8 | Question and connect | Problem-solving, discussion, reflection and collaboration |
| 9–11 | Reflect, discern and live the faith | Authentic dialogue, critical thinking, discernment and service |

Open `index.html` in any browser. Use the buttons at the top to show one age
group at a time, or print the page for a one-sheet staffroom reference (all
groups always print). It has no dependencies and supports light and dark mode.
